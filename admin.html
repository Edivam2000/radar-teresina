Como este painel funciona

leia com atenção
Sobre a senha: esta proteção roda no navegador. Ela impede acesso casual de quem pega seu computador, mas não é segurança de servidor — qualquer pessoa com conhecimento técnico pode ver o código da página. Para proteção de verdade (com senha validada em servidor e leads guardados em banco de dados), é preciso um back-end.
Leads e visitas ficam salvos no armazenamento deste navegador. Se você abrir a página em outro computador ou limpar os dados do navegador, os registros não acompanham — use o backup ao lado para guardar.
